Personal Health Export

A personal-use tool operated by the owner of the GitHub account yydleo, for backing up their own Fitbit data through the Google Health API and producing a daily summary in their own Google Drive.

What the application does

The application retrieves exercise, steps, sleep, heart-rate variability, oxygen saturation, resting heart rate and respiratory rate records. It stores dated raw-data archives in private Google Cloud Storage and updates a Google Docs summary containing descriptive statistics.

Why Google access is requested

  • Activity and fitness read access: retrieve exercise and steps.
  • Sleep read access: retrieve sleep records and stages.
  • Health metrics read access: retrieve HRV, oxygen saturation, resting heart rate and respiratory rate.
  • Drive file access: create and update the summary document created by this application.

Health and Drive access use separate OAuth clients. The tool does not request permission to modify health records or unrestricted access to all Drive files.

Scope and availability

This tool is for its operator's personal use; it is not a public signup service. It provides descriptive statistics, not official Premium scores, medical predictions, diagnosis or treatment advice. It is independently operated and is not affiliated with or endorsed by Google or Fitbit.

Read the privacy policy for data storage, retention and deletion details. Support is available through the operator's support email displayed on the Google OAuth consent screen.
